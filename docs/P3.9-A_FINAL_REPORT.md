**Chunking and idempotency contract:**

* Input: `ExtractedContent` + `run_id`, `user_id`, `source_id`.
* Output: `SourceChunkSet(source_id, run_id, chunks, normalized_char_count, replaced_count)`.
* Algorithm: normalize → sentence units → greedy pack → merge short → ceiling check → PassageSpan tuples.
* Idempotency: transactional replace (`delete_for_source` + re-insert in one UoW). No overlap between chunks (avoids duplicate evidence identity). Citation guard: if `CitationRepository.count_for_source(source_id) > 0`, raise `ChunkReplaceBlockedError`.
* Empty/whitespace content: writes nothing, does not delete existing passages.
* Downs stream: chunks loadable through existing `SourceChunkRepository.list_for_source`, consumable by `SourceEvidenceService`.

**Ranking metadata persistence contract:**

* Input: `SourceRanking(source_id, rank, quality_score, content_hash, duplicate_of_id)`.
* Validation: rank ≥ 1, quality ∈ [0,1], content_hash must be exactly 64 hex chars (SHA-256), duplicate_of_id must reference a source in the same run (not self), cannot duplicate to None unless allowed.
* Persistence: `UPDATE sources SET rank=..., quality_score=..., content_hash=..., duplicate_of_id=..., updated_at=NOW() WHERE id=... AND run_id=...`.
* Ownership checks: every named source_id must belong to the run_id; every duplicate_of_id must belong to the same run_id.
* Batch atomicity: all statements share the caller's unit of work; failure mid-batch rolls back the whole batch.
* Downstream: `CitationRepository.list_citable_for_run` and `plan_synthesis_context` observe persisted rank/quality.

**Schema/migration decision:**

* No migration was necessary. The existing `sources` table already has columns `rank`, `quality_score`, `content_hash`, `duplicate_of_id` with proper FK (`duplicate_of_id → sources NULL`, `ON DELETE SET NULL`) and indexes (`(run_id, rank)`, `(content_hash)`). The `set_rankings` method's ownership + duplicate-target checks replace the need for application-level constraints. Alembic drift check: "No new upgrade operations detected".
